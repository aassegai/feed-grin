# Feed Grin

An extension that hides user posts in the LinkedIn feed.

## Installation

1. Extract `feed-grin-1.0.1.zip` to a permanent folder.
2. Open `chrome://extensions` in Chrome.
3. Enable "Developer mode".
4. Click "Load unpacked" and select the `extension` folder
   inside the extracted archive. It must contain `manifest.json`.
5. Reload any LinkedIn tabs that are already open.
6. Open Chrome's extensions menu → Feed Grin. Here you can enable the trollface
   and turn off post hiding. Settings apply to open tabs immediately.

The same archive works on Windows, macOS, Linux, and ChromeOS. No native components
or build step are required.

To turn off post hiding, use the switch in settings. If you disable or
remove the extension itself through `chrome://extensions`, reload the tab.
After changing files, click the extension's Reload button and reload LinkedIn.
